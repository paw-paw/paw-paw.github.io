# MCP Future Extension

MCP is not required for this PAW Claude Code plugin candidate.

This directory records future extension ideas only. The plugin intentionally does
not ship `.mcp.json`, MCP servers, secrets, external services, or machine-local
paths.

Possible future uses:

- deterministic validator access;
- repository mapping;
- evidence collection;
- artifact registry lookup.

Any future MCP integration needs its own governed patch, opt-in configuration,
security review, and rollback plan.
