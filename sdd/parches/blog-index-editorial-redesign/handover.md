## Intencion preservada

El cambio busca rediseñar `/blog` para que pase de una superficie editorial limpia pero generica a una pagina mas autoral, escaneable y creible, manteniendo el sistema visual actual.

El handoff propone:

1. Hero izquierdo con copy editorial mas autoral.
2. Bloque `Editorial Background` con seis marcas y periodos.
3. Featured post mas editorial, con excerpt breve y CTA controlado.
4. Link integrado `Explore articles ↓`.
5. Cards regulares mas limpias, sin CTA textual separado y con flecha inline en el titulo.

---

## Decisiones de intake asociadas

- El conflicto entre el handoff y los contratos actuales del blog se trata como cambio contractual intencional, no como error del handoff.
- `Editorial Background` queda acotado a `/blog`; no se eleva en este cambio a entidad reusable global del portfolio.
- El cambio debe cerrar con paridad real entre `en` y `es`.
